# Landing Page — O Segredo da Empada que Derrete

Landing page oficial de alta conversão para o produto digital **O Segredo da Empada que Derrete**.

## Deploy na Vercel
1. Conecte este repositório na sua conta da Vercel.
2. Como se trata de um site estático, não há necessidade de build command nem de configuração de output directory (root `/`).
3. O deploy ocorre automaticamente em segundos.
